<h2>🧠 How Does It Work?</h2>

<p>git-iterm2is designed to be as <strong>intuitive</strong> as possible. Here's a quick rundown of its main features:</p>

<h3>🔍 Status</h3>

<p>This shows you the current state of your Git repository. It tells you which files have been <strong>modified</strong> (changed),which are <strong>untracked</strong> (new files Git doesn't know about yet),and which are <strong>staged</strong> (ready to be committed). You'll see a clean list,, color-coded for easy scanning.</p>

<h3>📝 Staging</h3>

<p>Staging is like putting files in a "waiting room" before you save them permanently (called a <em>commit</em>). With git-iterm2,, you can easily stage files by clicking a checkbox next to each file. You can stage individual files or all files at once. This is much easier than typing <code>git add</code> commands manually.</p>

<h3>📄 Diffs</h3>

<p>A "diff" shows you exactly what changed in a file — line by line. Added lines appear in green,, removed lines in red. This is incredibly useful for reviewing your work before committing. Just click on a file in the status list,, and the diff will appear right there.</p>

<h3>🌿 Branches</h3>

<p>Branches are separate versions of your project. You might have a branch for experimenting,, another for the stable version,, etc. git-iterm2 shows you all your branches,, which one you're currently on,, and lets you switch between them with a simple click.</p>

<h3>📈 Graph</h3>

<p>The graph is a visual representation of your project's history. It shows all your commits (snapshots of your work) as dots connected by lines,, showing how your project evolved over time. You can see branch merge points,, commits by different authors,, and more. It's like a family tree for your code.</p>

<h3>💾 Stashes</h3>

<p>Sometimes you need to quickly save your current work,, but you're not ready to commit it yet. That's what stashes are for. git-iterm2 lets you create stashes,, view them,, and apply them back when you're ready. It's like a bookmark for your uncompleted work.</p>
